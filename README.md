# Asian NLP Lab

Laboratório inicial para estudar NLP aplicado a línguas asiáticas, começando pelo coreano e com foco em explicações para falantes de português.

## Objetivo inicial

Criar pequenos experimentos para entender como modelos de linguagem processam frases em coreano, como gerar embeddings e como comparar frases por similaridade semântica.

## Primeira etapa

Notebook:

`notebooks/01_primeiro_contato_modelo.ipynb`

Esse notebook mostra:

- como carregar um modelo multilíngue;
- como tokenizar frases em coreano;
- como transformar frases em vetores;
- como comparar frases por similaridade;
- como buscar frases coreanas a partir de uma consulta em português.
